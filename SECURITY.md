# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

## What this extension stores

- Carrier records, MC/USDOT associations, and job checkpoints in **local IndexedDB only**
- No remote database, analytics beacon, or third-party collection API

## Reporting a vulnerability

Please open a [GitHub Security Advisory](https://github.com/mafzalkalwardev/carrier-source-free-data-collector/security/advisories/new) or contact the repository owner privately.

Include:

- Impact description
- Steps to reproduce
- Affected files / APIs if known

We aim to acknowledge reports within 7 days.

## Out of scope

- Attempts to bypass CarrierSource access controls, CAPTCHAs, or paid entitlements
- Requests for scraping credentials, session tokens, cookies, or contact PII extraction

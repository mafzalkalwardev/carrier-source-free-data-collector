CARRIERSOURCE GitHub

Chrome extension · Manifest V3

Free Data Collector

A local research side panel for carrier cards that are already visible on the page. It does not use an API, does not collect contact actions, and does not bypass site restrictions. You confirm permission before collection starts.

What the extension is for.

It reads freely visible carrier cards in your own browser, with optional enrichment of freely accessible profile pages. CarrierSource requires permission for collection, including manual extraction. The extension does not bypass access controls, CAPTCHAs, or paid gates.

Install it from the repository as an unpacked Manifest V3 extension. The product tour on this page is the public demo.
